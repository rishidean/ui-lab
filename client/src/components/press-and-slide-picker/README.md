# PressAndSlidePicker

A one-gesture picker for small, finite option sets — status, priority,
t-shirt size. Long-press the chip, slide to the option, release to
commit, with haptic ticks along the way. A plain click opens a
keyboard-friendly fallback listbox, so the fast path never excludes
anyone.

## Install

One command:

```bash
npx shadcn@latest add https://ui-lab.r7n.co/r/press-and-slide-picker.json
```

That copies the folder below into your components directory, adds the
two npm dependencies, and injects the CSS variables. No CLI? The lab's
Code tab offers `/r/press-and-slide-picker.zip` — the folder plus
`glass.css` and a generated `tokens.css`.

Or copy these files by hand:

- `components/press-and-slide-picker/` — `PressAndSlidePicker.tsx`,
  `PressAndSlidePicker.css`, `lib.ts`, `index.ts`
- `theme/glass.css` — the shared glass primitives; load it before the
  component's CSS

npm dependencies: `clsx`, `tailwind-merge` (for `cn` in `lib.ts`; point
the import at your own `cn` and drop both). React 18+ with `react-dom`
(the strip and listbox portal to `document.body`). No Tailwind needed —
the picker ships its own CSS.

## CSS variables

The picker reads these custom properties. Every one has an inline
fallback, so it renders without them; paste the block for the lab look.
Generated by `scripts/registry/collect-vars.mjs press-and-slide-picker`;
do not hand-edit.

  --blur-lg: 22px;

## Minimal usage

```tsx
import { useState } from "react";
import { PressAndSlidePicker, type PickerOption } from "@/components/press-and-slide-picker";

const status: PickerOption[] = [
  { key: "todo", label: "To Do", color: "#3B82F6", bg: "#DBEAFE" },
  { key: "in-progress", label: "In Progress", color: "#F59E0B", bg: "#FEF3C7" },
  { key: "done", label: "Done", color: "#22C55E", bg: "#DCFCE7" },
];

export function Task() {
  const [value, setValue] = useState("todo");
  return <PressAndSlidePicker options={status} value={value} onChange={setValue} />;
}
```

Props: `options` (3–6 items; `key`, `label`, `color`, optional `bg`),
`value`, `onChange(key)`, `itemWidth` (px per option, default 92),
`longPressDuration` (ms, default 275), `renderChip(option, isActive)`
to supply your own trigger, `disabled`.

## Interaction contract

- **Gesture.** Press and hold for `longPressDuration`. A hairline ring
  sweeps the chip over exactly that time, so the hold reads as
  registering. The strip appears below the chip (above if there is no
  room), current value pre-highlighted. Tracking starts once the pointer
  enters the strip's hit zone; crossing an option fires a light haptic;
  release commits (heavy haptic on change). Moving far away or pressing
  Escape cancels.
- **Tap.** Plain click, Enter, Space, or ArrowDown opens the fallback
  `role="listbox"`: arrow keys rove, Enter or Space selects, Escape or
  click-away dismisses and returns focus to the chip.
- **Scroll and resize** dismiss both surfaces without committing.

## What you own

- The option colours: per-option `color`/`bg` are props, never theme
  tokens.
- No transformed ancestor above the picker. The strip is
  `position: fixed` and portaled to `document.body`; a `transform` on
  any ancestor of the chip re-bases nothing in the portal, but a
  transform on an ancestor of the portal target would.
- Reduced motion: the sweep becomes a static ring and the strip's
  motion collapses, following `prefers-reduced-motion`.
